# Student Practice Hub

Practice plans, drills with scores, rounds, lesson notes and a weekly check-in for Karina Sánchez Golf students.

- `src/student` — the student and parent phone app
- `src/coach` — Karina's coach view
- `supabase/schema.sql` — database, sign-in rules and privacy rules
- `SETUP.md` — how it's deployed

Built with Vite and Supabase. `npm install`, then `npm run dev`.
